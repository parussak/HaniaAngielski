# Karty kursów

Tutaj zapisujemy informacje właściwe dla danego kursu i podręcznika. Nie kopiujemy tu wspólnej mechaniki, reguł powtórek ani list wszystkich słówek z plików materiałów.

**Ustalona definicja:** jeden kurs odpowiada jednemu podręcznikowi do danego języka. Dwa różne podręczniki do włoskiego oznaczają dwa osobne kursy. Dodruk i drobne poprawki pozostają w tym samym kursie; istotnie zmienione wydanie to osobny kurs. Model kursów jest wdrożony w etapie 2; obecny rejestr zawiera wyłącznie angielski z Food — D-11 i D-13 w [rejestrze](../decyzje.md).

| Kurs | Stan obecny |
| --- | --- |
| [Angielski Hani](angielski-hani.md) | W aplikacji jest moduł Food |
| [Francuski Hani](francuski-hani.md) | Uzgodniony kierunek, bez wdrożonych materiałów |
| [Włoski Pauliny](wloski-pauliny.md) | Uzgodniony kierunek A1/A2, bez wdrożonych materiałów |

Imiona w nazwach kart wskazują obecnych odbiorców materiału, nie wyłączność kursu dla jednej osoby. Kurs może być wspólny dla wielu kont, z osobnymi postępami — D-14 w [rejestrze](../decyzje.md). Sposób wyboru i prezentacji dostępnych kursów pozostaje w U-08.

Karta kursu zawiera odbiorcę, źródła, zakres, własne ustalenia językowe i sprawy do potwierdzenia. Wdrożony [format plików](../format-materialow.md) określa ich reprezentację w aplikacji; karty pozostają czytelnym opisem kontekstu.

Docelowy podstawowy opis kursu obejmuje nazwę, języki nauki i objaśnień, tytuł, autora i wydanie podręcznika, poziom lub zakres poziomów i uporządkowaną listę modułów (D-17). Strony i źródła konkretnych ćwiczeń są przy materiale modułu. Brakujących danych podręczników nie uzupełniamy zgadywaniem; ich potwierdzenie należy do U-10.

Zasady przygotowania i recenzji treści: [merytoryka](../04-merytoryka.md). Wspólne prowadzenie nauki: [nauka](../03-nauka.md). Własna polityka odpowiedzi nie może być ukrytym wyjątkiem w kodzie wspólnych ćwiczeń.
